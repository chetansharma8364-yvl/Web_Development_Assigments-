Web Development Course

This course teaches learners the fundamentals of HTML, CSS and web page development.

Course Objectives

  • Understand HTML page structure.
  • Create forms and tables.
  • Use links, images, audio and video.
  • Build simple responsive web pages.
  • Develop confidence in practical web development.
