Technical Terminology

RAM
Random Access Memory, used by the computer to store temporary data for fast processing access.
SSD
Solid State Drive, a fast storage device using flash memory to hold files permanently.
Refresh Rate
The number of times per second an image is redrawn on the screen, measured in Hertz (Hz).
Warranty
A manufacturer guarantee promising to repair or replace defective components within a set period.
